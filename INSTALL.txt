CloudDock 0.5.8 — macOS Apple Silicon

系统要求：macOS 14 或更新版本，M1 / M2 / M3 / M4 等 Apple Silicon Mac。

1. 打开 CloudDock-0.5.8-arm64.dmg。
2. 把 CloudDock.app 拖到 Applications。
3. 从“应用程序”打开 CloudDock，点击“新建连接”。
4. 选择存储服务，填写 Endpoint、Region 和访问凭据；凭据默认保存到软件本机，也可改为 macOS 钥匙串，测试后保存。

从旧版升级：等待传输结束，使用 ⌘Q 退出 CloudDock，再替换原位置的 App。
如果此前从项目 dist/CloudDock.app 运行，继续原位更新，不要同时在 Applications 留第二份。
项目内可运行 python3 scripts/install-local.py 安装已生成的新版本 ZIP。
替换 App 不删除连接、钥匙串、收藏或历史任务；无需重新添加连接。
安装完推出 DMG，避免从安装镜像运行。

选择 macOS 钥匙串保存时，系统可能弹出访问授权提示。软件本机模式的日常操作不调用钥匙串。
已有连接保留原来的钥匙串方式；升级不会自动迁移密钥。
要切换旧连接：右键连接 → 编辑连接 → 凭据保存方式选“软件本机” → 读取原凭据或重新填写 → 保存。
“读取已保存凭据”会按原保存方式读取；从钥匙串读取仍需系统授权。直接重新填写可不读取旧钥匙串。
切换成功后若旧副本未能移除，会明确提示；当前连接使用新位置。
这是本地 ad-hoc 签名版本，尚无 Apple Developer ID 签名及公证。
如果系统拦截，可在“系统设置 → 隐私与安全性”中选择“仍要打开”。
不需要安装 Node、Python 或 rclone 才能运行已打包 App。

使用提示：
- 双击存储桶和文件夹进入，双击文件预览；⌘R 刷新；⌘U 上传；⌘D 下载所选项。
- 从 Finder 拖入文件/目录上传。
- “操作”列的眼睛按钮预览，“手”图标拖到 Finder 下载，也可使用下载按钮。
- Cmd / Shift 多选；点击名称、大小、修改时间表头排序。
- 文件列表默认每页 100 项，可切换 50 / 200 项；搜索和子目录搜索按云端分页读取，界面显示检查进度，可随时停止。排序作用于当前页。
- 星标收藏当前位置；连接右键菜单可编辑或移除。
- 上传/下载发现同名文件时，可选跳过、覆盖或取消。同名目录合并，按该选择处理内部文件。
- 跳过会显示“已跳过”，不会误报上传成功；选择覆盖后即使大小、时间相同也重新传输。
- 任务支持取消、失败重试，以及 App 保持运行时的暂停/继续。
- “操作审计”查看上传、下载、文件变更及连接新增/编辑/删除，按连接、结果、时间等筛选。
- 审计默认每页 100 条，筛选、搜索和翻页不会一次性加载全部历史记录。
- 审计从 0.2.0 开始记录，重启及清空任务队列后保留；浏览和预览不记录。
- 文本预览最大 1 MiB，图片/PDF 最大 10 MiB，PDF 最多 200 页；其他类型可下载后查看。
- HTML、Markdown 和脚本显示为纯文本；预览内容不在本地缓存。
- 选中文件，点击工具栏或右键菜单“分享下载”，设置有效期后生成地址和二维码。
- 有效期可选 15 分钟、1 小时、1 天、7 天，或自定义分钟/小时/天；范围 1 分钟至 7 天。
- “生成并复制地址”一步完成分享；也可单独生成后复制地址、复制二维码或保存 PNG。
- 修改有效期后需重新生成，已发出的旧链接不会自动失效；到期时间在分享窗口显示。
- 下载分享审计从 0.3.0 开始，不保存完整签名地址；打开窗口与复制不新增记录。

配置与审计位置：~/Library/Application Support/CloudDock/
state.json 保存连接/收藏/任务；audit.jsonl 为本机操作日志，不记录凭据。
Credentials 目录保存本机加密凭据与解密材料，保护依赖当前 Mac 账户；备份时完整保留该目录。

Google Cloud Storage 已在新建连接列表中。真实 Google 使用服务账号 JSON；本地 fake-gcs-server 使用 `http://localhost:4443/storage/v1/`，不需要服务账号 JSON。
MinIO 需填写 S3 API 端口，通常是 9000，不是 Console 的 9001。
LocalStack 选择 Amazon S3，通常填写 http://localhost:4566、test/test，Region 与建桶时一致。本机/IP 地址自动使用 Path-style，无需修改已有连接。
0.5.3 修复 MinIO 列表中空格被显示为加号的问题。升级后刷新目录并重新选择文件操作，旧失败任务仍保留当时的路径，请勿直接重试该类错误任务。
0.5.5 恢复 Google Cloud Storage 新建入口，支持本地 fake-gcs-server 的 `/storage/v1/` Endpoint，并增加 ARM64 本地兼容测试；不会改变已有连接数据。
0.5.6 修复旧的本地 Google Endpoint 缺少 API 路径时删除/下载失败；旧连接无需重建。新增 Google V4 限时分享；本地 fake-gcs-server 提供无自动过期的下载直链与二维码，不伪装成限时签名。
0.5.7 修复左侧连接行未选中时空白区域无法点击的问题。整行均可点击切换；空白区域右键显示该行连接的菜单，菜单顶部显示连接名称。
fake-gcs-server 是社区 GCS 模拟器，不是 Google 官方镜像；本地测试不等价于真实 Google OAuth、IAM、计费项目或云端权限测试。
没有列桶权限时，在连接中指定 bucket 名称。

边界：未提供跨云复制、同步、版本历史、ACL 编辑或 Google OAuth。
进程退出后可重试，但不保证从大文件上传中断点恢复。
下载分享支持单个 S3/MinIO/OSS/S3 兼容/GCS 文件，暂不支持文件夹。真实 GCS 使用服务账号私钥签名；本地模拟器不执行有效期校验。localhost / 127.0.0.1 下载地址仅本机可访问。
接收方需能访问存储地址；临时凭据过期、权限变化或文件删除可能使分享提前失效。
真实各云账号尚需在你的环境中验证。请先用测试 bucket 验收。
