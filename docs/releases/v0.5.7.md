CloudDock is a native object storage client for Apple Silicon Macs. Manage Amazon S3, MinIO, Alibaba Cloud OSS, Google Cloud Storage, and compatible services from one workspace.

## Highlights

- Browse buckets and folders, bookmark locations, and search with paginated file lists.
- Upload and download files or folders, including Finder drag-and-drop, with explicit skip/overwrite choices.
- Preview supported small text files, images, and PDFs.
- Share single-file downloads with configurable expiry, one-click link copying, and QR codes. Local fake-gcs-server links are direct links without enforced expiry.
- Review local operation history across connections and choose local encrypted credentials or macOS Keychain.
- Click anywhere in a sidebar connection row to switch connections; right-click actions apply to that row.

## Installation

Requires **macOS 14+ on Apple Silicon**. The app interface is **Simplified Chinese**.

- Download **CloudDock-0.5.7-arm64.dmg**, open it, and drag CloudDock.app into Applications.
- Alternatively, extract **CloudDock-0.5.7-arm64.zip**.
- Quit the previous app and replace it in its existing location when upgrading.
- `-source.zip` and GitHub's Source code assets are for developers.

Packages are ad-hoc signed and **not notarized by Apple**. See the README for first-launch guidance or source build instructions. To verify downloaded assets, place them alongside `SHA256SUMS` and run `shasum -a 256 -c SHA256SUMS`.

## Verification scope

Local checks cover storage pagination, transfers, overwrite handling, previews, credentials, operation history, signing, and QR encoding. Compatibility tests use MinIO, LocalStack, Moto, and fake-gcs-server fixtures. They do not replace real cloud IAM or account-permission testing. Finder drag-and-drop and macOS authorization dialogs need manual verification.
