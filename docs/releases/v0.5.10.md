CloudDock 0.5.10 fixes installer creation after the macOS release runner reported `No space left on device` while copying the bundled rclone into a DMG. App compilation and signing had completed successfully.

## Changes

- Build an HFS+ disk image with explicit capacity based on file sizes, plus 64 MiB of spare space and a 256 MiB minimum.
- Mount the finished DMG read-only and verify that every application file matches the ZIP package, including the transfer engine and code signature.
- Validate packaging changes on `main`, show failure excerpts in check results, and support retrying an unpublished release at its original tag.
- Retain the 0.5.9 version-display fix: the workspace footer reads the installed app version.

## Installation

Requires **macOS 14+ on Apple Silicon**. Download **CloudDock-0.5.10-arm64.dmg** or **CloudDock-0.5.10-arm64.zip**, quit the previous app, and replace it in the same location. The bundle version is **0.5.10**, build **15**.

Packages are ad-hoc signed and not notarized by Apple. See the README for first-launch guidance. The source ZIP is for developers. `SHA256SUMS` contains the installer and source archive checksums.
