CloudDock 0.5.9 fixes the version shown in the workspace footer. The 0.5.8 app bundle displayed a hard-coded `0.5.7` after installation, making the update appear unsuccessful. The footer now reads the installed bundle version; source runs without bundle metadata show a development label.

The English and Chinese READMEs also include real app screenshots covering the file workspace, connection settings, download sharing, and operation history. Private identifiers and share data are redacted.

## Installation

Requires **macOS 14+ on Apple Silicon**. Download **CloudDock-0.5.9-arm64.dmg** or **CloudDock-0.5.9-arm64.zip**, quit the previous app, and replace it in its existing location. The bundle version is **0.5.9**, build **14**. Connections and history remain separate from the app bundle.

Packages are ad-hoc signed and not notarized by Apple. See the README for first-launch guidance. `-source.zip` is for developers. Use `SHA256SUMS` to verify the downloads.

## Verification

The release workflow runs core checks and the isolated Moto S3 integration suite, builds the installers, and verifies bundle metadata, architecture, signatures, source contents, and checksums. This change affects version display and documentation; it does not establish additional hosted-cloud compatibility.
